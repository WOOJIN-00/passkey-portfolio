잠김

심사하시는 분은 이 영역을 열 필요가 없습니다. 위쪽 공개 소개까지만 보시면 됩니다.

이 기기에는 아직 패스키를 저장할 수 없습니다. 그래서 Windows가 USB 보안 키만 물어볼 수 있습니다. 아래 중 하나를 해 주세요.
  1. Windows Hello PIN 만들기 (가장 쉬움): 설정 → 계정 → 로그인 옵션 → PIN(Windows Hello) → 설정. PIN을 만든 뒤 이 페이지를 새로고침하고 "이 기기"를 고르세요.
  2. Chrome 비밀번호 관리자에 저장: Chrome에 Google 계정으로 로그인하고 동기화를 켠 뒤 "이 기기"를 고르세요.
  3. 휴대폰에 저장: 이 PC에 블루투스가 켜져 있어야 QR 코드 방식이 동작합니다.
